Equipment Room Control Demonstration

Interactive software reference model. Values and outputs are simulated. This page neither connects to hardware nor proves a completed installation. All EEPROM bytes stay in this page's memory.

Environment and inputs

Controller outputs

Fan OFF
LOCKED
Buzzer OFF

Access: idle

Active alarms

    Fan OFF ≤28°C, ON ≥32°C. Acknowledge silences current alarms while keeping their indications. A new condition reactivates the buzzer.

    Persistent settings

    Two settings slots model the PIC's internal EEPROM. Power cycle keeps these simulated bytes but clears runtime states; reloading the page resets the entire demonstration. A real power-loss test remains part of commissioning.
